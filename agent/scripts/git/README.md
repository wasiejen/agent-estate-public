# scripts/git — cross-tree git helpers (branch sync by merge)

| script | what it does | tested (2026-10-22) |
|---|---|---|
| `port_sync.cjs` | syncs MAIN's `main` branch into the v2 clone's `migration` branch by MERGE (#147). DEFAULT = dry run: fetch into the clone, print the merge-tree conflict set, the per-path resolution plan, and the exact commands, then `zero-mutation: PROVEN` (status+HEAD snapshot of BOTH trees, diffed to empty). `--apply` = `git merge --no-commit FETCH_HEAD` -> `--theirs` resolutions -> discovery guard -> clone gate (probe + v1 node smokes + v2 bun smokes + tsgo) -> on FAIL: `gate: FAIL` + `git merge --abort`; on green: `gate: PASS` + `merge staged, not committed` (it NEVER commits the merge; the first real apply is the maintainer's act) | `node agent/scripts/git/port_sync.cjs` (dry, real-tree defaults) -> `merge-tree: 7 conflict(s)`, 6 plan lines `take MAIN (--theirs)` + 1 `config: kept branch-local (host-owned)`, `zero-mutation: PROVEN`, exit 0 |
| `port_sync.selftest.cjs` | the selftest: runs against a THROWAWAY git repo pair under the scratchpad `home/AppData/Local/Temp/opencode/port_sync_selftest/` (never a real tree); covers both resolution glob sets, `opencode.jsonc` never touched, the guard move, the gate-FAIL abort | `node agent/scripts/git/port_sync.selftest.cjs` -> `checks: 84 pass=84 fail=0` + `SELFTEST: ALL PASS`, exit 0 |

Boundary as ruled by the maintainer 2026-10-22 (#147): take MAIN (`--theirs`) for `.opencode/tools/`, `.opencode/plugin/probes/`, `.opencode/plugin/tests/`, `agent/handover/`, `loop/`, `TODO.md`, `agent/knowledge/`, `agent/memory/`, `agent/readme/`, `agent/scripts/`; `opencode.jsonc` is host-owned -> NEVER written (resolved to the clone's OWN side, content byte-identical, MAIN's side never lands); everything else merges by git's own 3-way.
Excluded: `opencode.jsonc` in either tree, MAIN's tree (fetch-source only — no merge/commit/add), `.opencode/plugins/**`, `.opencode/plugin-unported-v1/**` content edits, deletions, `git push`; an agent never runs `--apply` against the real trees.
Env overrides: `PORT_SYNC_MAIN`, `PORT_SYNC_CLONE`, `BUN_EXE`, `TSGO_EXE`. The script refuses to run on a branch mismatch or a dirty clone.
Usage: `node agent/scripts/git/port_sync.cjs` (dry run) | `... --apply [--no-gate] [--main <p>] [--clone <p>]` | `node agent/scripts/git/port_sync.selftest.cjs`.
